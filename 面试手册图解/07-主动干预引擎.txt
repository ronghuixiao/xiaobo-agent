│  │                                                                         │    │

┌─────────────────────────────────────────────────────────────────────────────────┐
│                              设计决策                                            │
│                                                                                 │
│  为什么用规则引擎而不是LLM?                                                     │
│  • 主动干预需要定时执行，如果每次都调LLM生成，成本很高                          │
│  • 规则简单明确: 24h内负面情绪>60% → 发关怀，不需要LLM判断                      │
│  • 规则有冷却机制，LLM很难保证不重复打扰                                        │
│                                                                                 │
│  权衡:                                                                          │
│  • 规则不够灵活 (新增场景需要改代码)                                            │
│  • 但对于固定的关怀场景 (情绪、沉默、屏幕时间)，规则足够且更可靠                │
└─────────────────────────────────────────────────────────────────────────────────┘
