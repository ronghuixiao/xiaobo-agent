│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                         ToolRegistry (注册中心)                          │    │
│  │                                                                         │    │
│  │  register(tool)  →  按名称 O(1) 查找                                   │    │

│  │                         ToolExecutor (执行器)                            │    │
│  │                                                                         │    │
│  │  1. parse_tool_calls(text)  → 解析LLM输出中的JSON工具调用              │    │

│  │  3. execute_calls(calls)    → 执行所有工具调用                          │    │
│  │  4. format_results_for_context(results) → 格式化结果给LLM              │    │

┌─────────────────────────────────────────────────────────────────────────────────┐
│  工具调用流程                                                                    │
│                                                                                 │
│  用户: "现在几点了？"                                                           │
│         │                                                                       │
│         ▼                                                                       │
│  Handler 构建系统提示 (含工具描述)                                              │
│         │                                                                       │
│         ▼                                                                       │
│  LLM 输出: "我帮你查一下
{"tool": "get_time", "args": {"format": "full"}}"     │
│         │                                                                       │
│         ▼                                                                       │
│  ToolExecutor.has_tool_calls() → True                                           │
│         │                                                                       │
│         ▼                                                                       │
│  ToolExecutor.process_with_tools()                                              │
│    ├─ parse_tool_calls() → [{"tool": "get_time", "args": {"format": "full"}}]  │
│    └─ execute_calls() → TimeTool.execute(format="full")                         │
│       → {"datetime": "2026-07-30 16:00:00", "weekday": "星期三"}                │
│         │                                                                       │
│         ▼                                                                       │
│  注入工具结果，再次调用LLM                                                      │
│         │                                                                       │
│         ▼                                                                       │
│  LLM最终回复: "现在是 2026年7月30日 星期三 16:00"                               │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  Skill触发流程                                                                  │
│                                                                                 │
│  用户: "日报"                                                                   │
│         │                                                                       │
│         ▼                                                                       │
│  Handler.handle_message()                                                       │
│         │                                                                       │
│         ▼                                                                       │

│    → 匹配到 DailyReport Skill                                                   │
│         │                                                                       │
│         ▼                                                                       │
│  SkillRegistry.execute(DailyReport, context)                                    │
│    → 生成日报内容                                                               │
│         │                                                                       │
│         ▼                                                                       │
│  返回 SkillResult.success=True, content="今日日报..."                           │
│         │                                                                       │
│         ▼                                                                       │
│  直接返回给用户 (不走LLM)                                                       │

┌─────────────────────────────────────────────────────────────────────────────────┐
│                              扩展新工具 (热插拔)                                 │
│                                                                                 │
│  3步完成:                                                                       │
│                                                                                 │
│  # 1. 继承 BaseTool                                                             │
│  class WeatherTool(BaseTool):                                                   │
│      name = "get_weather"                                                       │
│      description = "查询天气"                                                   │
│      parameters = [ToolParameter(name="city", type="string")]                   │
│      async def execute(self, city="", **kwargs):                                │
│          return ToolResult(success=True, data={"weather": "晴"})                │
│                                                                                 │
│  # 2. 注册                                                                      │
│  tool_registry.register(WeatherTool())                                          │
│                                                                                 │
│  # 3. 完成。LLM自动看到新工具                                                   │
│                                                                                 │
│  关键: 设计模式                                                                 │
│  • 注册表模式 (Registry Pattern): 工具自注册，按名称O(1)查找                    │
│  • 策略模式 (Strategy Pattern): 每个工具是独立策略，实现相同接口                │
│  • 管道模式 (Pipeline): LLM输出→解析→执行→结果回注→LLM继续                     │
└─────────────────────────────────────────────────────────────────────────────────┘
