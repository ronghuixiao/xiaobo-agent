┌─────────────────────────────────────────────────────────────────────────────────┐
│                              调用链路图                                          │
│                                                                                 │
│  用户消息 → LLMResilience.chat()                                                │
│      │                                                                          │
│      ├─ 熔断检查: OPEN → 直接返回兜底提示                                       │
│      │                                                                          │
│      ├─ 缓存检查: 命中 → 返回缓存                                               │
│      │                                                                          │
│      └─ 调用LLM:                                                                │
│          ├── 成功 → 写缓存 → 返回回复                                           │
│          └── 失败 → 记录失败次数 → 返回兜底                                     │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  重试机制 (retry.py):                                                    │    │
│  │  指数退避: 1s → 2s → 4s → 8s → 16s → 30s(上限)                          │    │
│  │  最多重试3次                                                             │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│                              为什么需要三层?                                     │
│                                                                                 │
│  LLM不是永远可用的:                                                             │
│  • 网络抖动                                                                     │
│  • API限流                                                                      │
│  • 服务宕机                                                                     │
│  • 超时                                                                         │
│                                                                                 │
│  三层防护确保:                                                                  │
│  1. 熔断: 故障时快速失败，不加重故障                                            │
│  2. 缓存: 减少LLM调用，提升性能                                                │
│  3. 兜底: 用户永远能收到回复，不会卡住                                          │
└─────────────────────────────────────────────────────────────────────────────────┘
