用户消息进入
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  STEP 1 💾 保存用户消息                                                      │
│  ┌─────────────────────────────────────────────┐                            │
│  │ conversations.append(user_message)           │                            │
│  │ → 持久化到数据库                              │                            │
│  └─────────────────────────────────────────────┘                            │
│                              │                                               │
│                              ▼                                               │
│  STEP 2 🔍 检索相关记忆                                                      │
│  ┌─────────────────────────────────────────────┐                            │
│  │ memory.search(query=user_message)            │                            │
│  │ → 从5+1层记忆中检索相关上下文                  │                            │
│  │ → EmbeddingCache + 余弦相似度                 │                            │
│  └─────────────────────────────────────────────┘                            │
│                              │                                               │
│                              ▼                                               │
│  STEP 3 📝 构建Prompt                                                        │
│  ┌─────────────────────────────────────────────┐                            │
│  │ system_prompt + 相关记忆 + 用户消息            │                            │
│  │ → 拼装完整上下文                              │                            │
│  │ → 注入角色设定 + 个性特征                      │                            │
│  └─────────────────────────────────────────────┘                            │
│                              │                                               │
│                              ▼                                               │
│  STEP 4 🤖 调用LLM                                                          │
│  ┌─────────────────────────────────────────────┐                            │
│  │ llm_factory.create().generate(prompt)        │                            │
│  │ → Ollama(本地) 或 OpenAI(云端)               │                            │
│  │ → 三层容错保障                                │                            │
│  └─────────────────────────────────────────────┘                            │
│                              │                                               │
│                              ▼                                               │
│  STEP 5 🧹 清理标签                                                          │
│  ┌─────────────────────────────────────────────┐                            │
│  │ strip_internal_tags(response)                │                            │
│  │ → 移除 <thinking> <tool_call> 等内部标签      │                            │
│  │ → 用户只看到干净回复                          │                            │
│  └─────────────────────────────────────────────┘                            │
│                              │                                               │
│                              ▼                                               │
│  STEP 6 💾 保存助手回复                                                      │
│  ┌─────────────────────────────────────────────┐                            │
│  │ conversations.append(assistant_response)     │                            │
│  │ → 持久化到数据库                              │                            │
│  └─────────────────────────────────────────────┘                            │
│                              │                                               │
│                              ▼                                               │
│  STEP 7 ⚡ 异步提取信息 (fire-and-forget)                                      │
│  ┌─────────────────────────────────────────────┐                            │
│  │ asyncio.create_task(                         │                            │
│  │     extract_info(user_msg, response)         │                            │
│  │ )                                            │                            │
│  │ → 提取 facts / emotions / topics             │                            │
│  │ → 不阻塞主回复流程                            │                            │
│  └─────────────────────────────────────────────┘                            │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
回复返回用户 ✅
