║            ⚙️ LLM配置
║         怎么切换AI模型
╚══════════════════════════════════════════════════════════════════╝

配置文件: config/config.yaml

两个后端:
┌──────────────────────────────────────────────────────────────────┐
│  Ollama (本地)                                                    │
│  • 地址: http://localhost:11434                                  │
│  • 模型: qwen2.5:1.5b                                            │
│  • Embedding: nomic-embed-text                                   │
│  • 免费，隐私安全                                                │
│  • 需要本地安装Docker+Ollama                                     │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│  OpenAI (云端)                                                    │
│  • 地址: https://api.openai.com/v1                               │
│  • 模型: gpt-4o-mini                                             │
│  • 花钱，但更聪明                                                │
│  • 也支持其他兼容API (如MiMo)                                    │
└──────────────────────────────────────────────────────────────────┘

切换方式: 改配置文件的provider字段
  provider: ollama → 用本地
  provider: openai → 用云端

关键参数:
  temperature: 0.7(闲聊) / 0.4(学习)
  max_tokens: 2048 (最大生成长度)

Embedding固定用Ollama:
  因为云端API通常不支持embedding
