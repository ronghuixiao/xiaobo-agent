║         就像一封信从寄出到收到回信                                ║
╚══════════════════════════════════════════════════════════════════╝

你在微信发了一条: "今天心情不错"

第1步: 📨 消息出门
┌──────────────────────────────────────────────────────────────┐
│  你的手机                                                    │
│  ┌────────────────────────────────────────────────────────┐  │
│  │ 微信聊天框                                            │  │
│  │ 你: 今天心情不错                           [发送]     │  │
│  └────────────────────────────────────────────────────────┘  │
│                          ↓                                   │
│  微信 → iLink API → 服务器                                   │
└──────────────────────────────────────────────────────────────┘

第2步: 🚦 看门大爷检查 (CommandDispatcher)
┌──────────────────────────────────────────────────────────────┐
│  CommandDispatcher 就像小区门口的看门大爷:                    │
│                                                              │
│  "今天心情不错" → 这是聊天，送到对话处理器                   │
│  "日报"         → 这是命令，送到日报生成器                   │
│  "周报"         → 这是命令，送到周报生成器                   │
│                                                              │
│  看门大爷把消息分发到正确的部门                              │
└──────────────────────────────────────────────────────────────┘

第3步: 📋 检查任务关键词
┌──────────────────────────────────────────────────────────────┐
│  "今天心情不错" → 没有任务关键词 → 跳过                       │
│                                                              │
│  如果是 "今日任务：背单词；刷题" → 正则匹配到 → 保存任务     │
└──────────────────────────────────────────────────────────────┘

第4步: 🧠 小柏开始处理 (核心7步)
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  4.1 📝 把你说的话存到日记本                                 │
│      "今天心情不错" → 写入数据库                             │
│                                                              │
│  4.2 🔍 翻小本本，找相关信息                                 │
│      ├── 翻事实本: 荣慧喜欢..., 荣慧的目标是...             │
│      ├── 搜相关记忆: 上次聊心情是什么时候？                 │
│      └── 看今日任务: 有什么待办？                            │
│                                                              │
│  4.3 📝 给AI写一张"提示卡"                                   │
│      "你是小柏，荣慧的朋友。她的信息: ..."                   │
│      "相关记忆: ..."                                         │
│      "今日任务: ..."                                         │
│                                                              │
│  4.4 🤖 把提示卡交给AI，让它回复                             │
│      AI思考中...                                             │
│                                                              │
│  4.5 🧹 清理AI回复中的内部标记                               │
│      AI可能会写 [TASKS_DETECTED]... 这种内部代码             │
│      清理掉，不让你看到                                       │
│                                                              │
│  4.6 💾 把回复也存到日记本                                    │
│                                                              │
│  4.7 🔬 异步分析你说的话 (不耽误回复)                        │
│      ├── 提取事实: 今天心情不错 → event                     │
│      ├── 记录情绪: happy 80%                                 │
│      └── 打标签: 心情                                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘

第5步: ✅ 检查有没有任务完成
┌──────────────────────────────────────────────────────────────┐
│  "今天心情不错" → 没有任务完成的含义 → 跳过                   │
│                                                              │
│  如果是 "背完了" → AI判断 → 背单词任务标记完成               │
└──────────────────────────────────────────────────────────────┘

第6步: 📤 回复发回给你
┌──────────────────────────────────────────────────────────────┐
│  小柏: "听起来心情不错啊，有什么好事吗？"                    │
│                                                              │
│  服务器 → iLink API → 微信 → 你的手机                        │
└──────────────────────────────────────────────────────────────┘

💡 重点: 第4.7步是"fire and forget"
┌──────────────────────────────────────────────────────────────┐
│  就像你寄完信，不用等邮局分拣完才去做别的事                  │
│  回复先给你，分析慢慢做                                       │
│  这样你不用等，体验更好                                       │
└──────────────────────────────────────────────────────────────┘
