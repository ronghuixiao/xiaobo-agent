
╔══════════════════════════════════════════════════════════════════╗
║            🔬 信息怎么提取？                                      ║
║         AI从你的话里"提炼"出有用信息                              ║
╚══════════════════════════════════════════════════════════════════╝

你说了一句话，小柏要做3件事:

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  你: "昨晚学了反向传播，终于搞懂了链式法则，挺开心的"            │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  事1: 提取事实 (facts)                                     │  │
│  │  ──────────────────────────────────────────────────────    │  │
│  │                                                             │  │
│  │  问AI: "这句话里有什么事实？"                               │  │
│  │                                                             │  │
│  │  AI回答:                                                    │  │
│  │  {                                                          │  │
│  │    "facts": [{                                              │  │
│  │      "fact_type": "event",     ← 什么类型                  │  │
│  │      "subject": "学习",        ← 关于什么                  │  │
│  │      "content": "学了反向传播", ← 具体内容                 │  │
│  │      "confidence": 0.9,        ← 可信度                    │  │
│  │      "event_time": "2026-07-29 22:00"  ← 什么时候          │  │
│  │    }]                                                       │  │
│  │  }                                                          │  │
│  │                                                             │  │
│  │  💡 注意: event_time是绝对时间，不是"昨晚"                 │  │
│  │     因为AI可能不知道"昨晚"是哪天                           │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  事2: 记录情绪 (emotions)                                  │  │
│  │  ──────────────────────────────────────────────────────    │  │
│  │                                                             │  │
│  │  问AI: "这句话的情绪是什么？"                               │  │
│  │                                                             │  │
│  │  AI回答:                                                    │  │
│  │  {                                                          │  │
│  │    "emotion": {                                             │  │
│  │      "type": "happy",        ← 开心                       │  │
│  │      "intensity": 0.8,       ← 开心程度80%                │  │
│  │      "context": "终于搞懂了"  ← 为什么开心                 │  │
│  │    }                                                        │  │
│  │  }                                                          │  │
│  │                                                             │  │
│  │  只有非neutral的情绪才存，neutral不存                      │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  事3: 打标签 (topics)                                      │  │
│  │  ──────────────────────────────────────────────────────    │  │
│  │                                                             │  │
│  │  问AI: "这句话涉及哪些话题？"                               │  │
│  │                                                             │  │
│  │  AI回答:                                                    │  │
│  │  {                                                          │  │
│  │    "topics": ["反向传播", "链式法则", "深度学习"]           │  │
│  │  }                                                          │  │
│  │                                                             │  │
│  │  这些标签用于: 关联索引，方便以后查找                      │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  事4: 判断是否在学习                                       │  │
│  │  ──────────────────────────────────────────────────────    │  │
│  │                                                             │  │
│  │  问AI: "这是在学习吗？"                                     │  │
│  │                                                             │  │
│  │  AI回答:                                                    │  │
│  │  {                                                          │  │
│  │    "is_learning": true,                                     │  │
│  │    "learning_info": {                                       │  │
│  │      "topic": "反向传播",                                   │  │
│  │      "content": "理解了链式法则",                           │  │
│  │      "understanding": "搞懂了"                              │  │
│  │    }                                                        │  │
│  │  }                                                          │  │
│  │                                                             │  │
│  │  如果是学习内容 → 存到学习记录本                           │  │
│  │  并且切换对话模式: 回复更长，追问细节                      │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  🔑 关键设计: Fire and Forget                                    │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  时间线:                                                         │
│                                                                  │
│  你说完话                                                      │
│     │                                                            │
│     ├─→ 立刻回复你 ("不错啊！") ← 你不用等                     │
│     │                                                            │
│     └─→ 同时后台分析 (提取事实+情绪+标签) ← 慢慢做             │
│                                                                  │
│  就像:                                                           │
│  你问服务员: "今天有什么推荐？"                                  │
│  服务员: "推荐红烧肉" (立刻回答)                                 │
│  后厨同时在准备 (你不用等后厨做完才能问下一个问题)              │
│                                                                  │
│  好处: 你不用等，体验更好                                        │
│  坏处: 如果分析失败，可能丢失一些记忆 (但回复不受影响)          │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  💡 为什么要用绝对时间？                                         │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你说: "昨晚学了反向传播"                                        │
│                                                                  │
│  ❌ 如果存"昨晚":                                                │
│  一周后AI看到"昨晚学了反向传播"                                  │
│  AI会以为是一周后的昨晚，搞错时间！                              │
│                                                                  │
│  ✅ 存绝对时间:                                                  │
│  存 "2026-07-29 22:00 学了反向传播"                              │
│  一周后AI看到，知道是7月29日的事                                 │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
