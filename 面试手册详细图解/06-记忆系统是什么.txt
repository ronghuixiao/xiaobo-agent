
╔══════════════════════════════════════════════════════════════════╗
║            📓 记忆系统是什么？                                    ║
║         小柏的"小本本"，记住你说过的所有事                       ║
╚══════════════════════════════════════════════════════════════════╝

想象小柏有6个小本本，每个记不同类型的事情:

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  📖 本子1: 日记本 (conversations)                                │
│  ────────────────────────────────────────────────────────────    │
│  记录你说的每一句话                                              │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ 7月20日 14:30  你: "今天学了Python"                        │  │
│  │ 7月20日 14:30  小柏: "不错啊，学到哪了？"                  │  │
│  │ 7月20日 14:31  你: "列表推导式"                            │  │
│  │ 7月20日 14:31  小柏: "这个挺实用的"                        │  │
│  │ ...                                                        │  │
│  └────────────────────────────────────────────────────────────┘  │
│  特点: 全部记录，一个不漏                                        │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  📝 本子2: 事实本 (facts)                                        │
│  ────────────────────────────────────────────────────────────    │
│  AI从你的话里提取出来的"事实"                                    │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  事实1: 荣慧喜欢吃火锅 (preference)                        │  │
│  │  事实2: 荣慧在学Python (event)                             │  │
│  │  事实3: 荣慧的目标是9月前完成项目 (goal)                   │  │
│  │  事实4: 荣慧晚上8-10点效率最高 (habit)                     │  │
│  │  事实5: 荣慧室友叫张三 (person)                            │  │
│  │  事实6: 荣慧认为Rust会取代C++ (opinion)                    │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  8种类型: person/preference/ability/goal/habit/event/commitment  │
│                                                                  │
│  💡 为什么要提取事实？                                           │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  你说: "我室友张三昨天请我吃了火锅，挺开心的"              │  │
│  │                                                             │  │
│  │  AI提取:                                                    │  │
│  │  • 室友叫张三 (person)                                      │  │
│  │  • 喜欢火锅 (preference)                                    │  │
│  │  • 7月20日吃了火锅 (event)                                  │  │
│  │                                                             │  │
│  │  下次你说"想吃火锅"，小柏就知道你本来就喜欢                │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  😊 本子3: 情绪本 (emotions)                                     │
│  ────────────────────────────────────────────────────────────    │
│  记录你每次聊天的情绪                                            │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  7月20日 14:30  happy 80%  "学了Python，挺开心"            │  │
│  │  7月21日 09:00  tired 60%  "昨晚没睡好"                    │  │
│  │  7月21日 20:00  anxious 70% "明天要交论文"                 │  │
│  │  7月22日 15:00  excited 90% "论文交了！"                   │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  8种情绪: happy/sad/anxious/excited/calm/frustrated/tired/neutral│
│                                                                  │
│  💡 有什么用？                                                   │
│  如果你连续好几次都是负面情绪，小柏会主动关心你                  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  🔗 本子4: 关联本 (associations)                                 │
│  ────────────────────────────────────────────────────────────    │
│  记录关键词和对话的对应关系                                      │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  "Python"   → 7月20日的对话                                │  │
│  │  "火锅"     → 7月19日的对话                                │  │
│  │  "论文"     → 7月21日的对话                                │  │
│  │  "算法"     → 7月18日的对话                                │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  💡 有什么用？                                                   │
│  你说"上次说的那个Python..."，小柏能快速找到相关对话            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  📋 本子5: 任务本 (tasks)                                        │
│  ────────────────────────────────────────────────────────────    │
│  记录你的待办任务                                                │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  ✅ 背单词     已完成  (你说"背完了")                       │  │
│  │  ⬜ 刷题       待办                                          │  │
│  │  ⬜ 看论文     待办                                          │  │
│  │  ⬜ 早间签到   系统任务 (每天自动创建)                       │  │
│  │  ⬜ 生成日报   系统任务 (每天自动创建)                       │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  两种来源:                                                       │
│  • 你说"今日任务：xxx" → 用户任务 (user-前缀)                   │
│  • 系统自动创建 → 系统任务 (today-前缀)                          │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  📚 本子6: 学习记录本 (learning_log)                             │
│  ────────────────────────────────────────────────────────────    │
│  专门记录你学习的内容                                            │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  7月20日                                                    │  │
│  │  主题: 反向传播                                             │  │
│  │  内容: 理解了链式法则在反向传播中的应用                      │  │
│  │  理解程度: 搞懂了                                           │  │
│  │  标签: 反向传播, 链式法则, 深度学习                         │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  💡 有什么用？                                                   │
│  小柏可以帮你回顾: "你之前学了反向传播，现在复习一下？"         │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

💡 总结: 6个本本各司其职
┌──────────────────────────────────────────────────────────────────┐
│  日记本: 记录原话 (全量)                                         │
│  事实本: 提炼关键信息 (8种类型)                                  │
│  情绪本: 追踪情绪变化 (8种情绪)                                  │
│  关联本: 快速查找相关对话                                        │
│  任务本: 管理待办事项                                            │
│  学习本: 记录学习内容                                            │
│                                                                  │
│  所有本本都放在一个数据库里 (SQLite)                             │
└──────────────────────────────────────────────────────────────────┘
