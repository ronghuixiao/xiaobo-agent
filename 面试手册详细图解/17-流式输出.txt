
╔══════════════════════════════════════════════════════════════════╗
║            🌊 流式输出                                            ║
║         为什么AI回复是一个字一个字蹦出来的？                      ║
╚══════════════════════════════════════════════════════════════════╝

你发消息后，小柏的回复是一个字一个字出现的，不是一下子全出来:

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  你: "今天心情不错"                                              │
│                                                                  │
│  等1秒...                                                        │
│  小柏: "有"                                                      │
│  等0.5秒...                                                      │
│  小柏: "有什么"                                                  │
│  等0.5秒...                                                      │
│  小柏: "有什么好事"                                              │
│  等0.5秒...                                                      │
│  小柏: "有什么好事吗？"                                          │
│                                                                  │
│  💡 这叫"流式输出"，像水流一样一点一点流出来                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  为什么要流式输出？                                              │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  ❌ 不流式 (等全部说完再显示):                                   │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  你: "今天心情不错"                                        │  │
│  │  等待3秒...                                                │  │
│  │  小柏: "有什么好事吗？"  ← 突然出现                        │  │
│  │                                                             │  │
│  │  问题: 3秒钟你不知道小柏在干嘛，以为卡了                   │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ✅ 流式输出:                                                    │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  你: "今天心情不错"                                        │  │
│  │  小柏: "有" ← 0.5秒就有了，你知道它在回复                  │  │
│  │  小柏: "有什么好事" ← 继续出现                             │  │
│  │  小柏: "有什么好事吗？" ← 完成                             │  │
│  │                                                             │  │
│  │  好处: 你一直在看，知道小柏在思考，体验更好                │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  技术实现: SSE (Server-Sent Events)                              │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  后端 (Python):                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  async for chunk in llm.stream_chat(messages):             │  │
│  │      yield f"data: {json.dumps({type: chunk,           │  │
│  │                                content: chunk})}\n\n"   │  │
│  │                                                             │  │
│  │  # 一个chunk一个chunk发给前端                               │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  前端 (JavaScript):                                              │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  const resp = await fetch(/api/chat/stream);             │  │
│  │  const reader = resp.body.getReader();                     │  │
│  │                                                             │  │
│  │  while (true) {                                            │  │
│  │      const { done, value } = await reader.read();          │  │
│  │      if (done) break;                                      │  │
│  │      // 解析chunk，更新页面                                 │  │
│  │  }                                                         │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  💡 为什么用SSE不用WebSocket？                                   │
│  • SSE是单向的 (服务器→客户端)，对话场景够用                     │
│  • 实现简单，浏览器原生支持                                      │
│  • WebSocket是双向的，更复杂，这个场景不需要                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
