翻译成人话: 一个读过很多书的AI，会说人话

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  LLM怎么工作的？                                                 │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你给AI一张"提示卡":                                             │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  系统: 你是小柏，荣慧的朋友                                │  │
│  │        她喜欢火锅，晚上学习效率最高                        │  │
│  │        相关记忆: 她上周学了反向传播                        │  │
│  │                                                             │  │
│  │  用户: 今天心情不错                                        │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  AI读完后，一个字一个字地"蹦"出来:                               │
│                                                                  │
│  "有" → "什么" → "好事" → "吗" → "？"                          │
│                                                                  │
│  最终: "有什么好事吗？"                                          │
│                                                                  │
│  💡 AI不是一次性说完，而是一个字一个字生成                       │
│     这就是为什么叫"流式输出"                                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  温度 (temperature) 是什么？                                     │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  温度控制AI回复的"随机性":                                       │
│                                                                  │
│  温度 0.7 (闲聊模式):                                            │
│  你: "今天心情不错"                                              │
│  AI可能回: "有什么好事吗？" / "不错啊" / "说说呗"               │
│  → 每次回复可能不一样，更自然                                    │
│                                                                  │
│  温度 0.4 (学习模式):                                            │
│  你: "解释一下反向传播"                                          │
│  AI可能回: "反向传播是..." (每次都差不多)                        │
│  → 回复更稳定，适合需要准确的场景                                │
│                                                                  │
│  💡 小柏会自动切换:                                              │
│  你聊日常 → 温度0.7 → 回复自然多样                              │
│  你聊学习 → 温度0.4 → 回复稳定准确                              │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
