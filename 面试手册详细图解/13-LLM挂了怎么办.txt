╚══════════════════════════════════════════════════════════════════╝

LLM不是永远可用的，可能会:
• 网络断了
• API限流 (用太多被限制)
• 服务器宕机
• 超时

如果LLM挂了，小柏怎么办？

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  第一层防护: 🚦 熔断器                                           │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  就像电路的保险丝:                                               │
│                                                                  │
│  正常状态 (CLOSED):                                              │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  你: "今天心情不错"                                        │  │
│  │  → 调用LLM → 成功 → 返回回复                              │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  连续失败5次后，熔断 (OPEN):                                     │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  你: "今天心情不错"                                        │  │
│  │  → 检测到熔断 → 不调用LLM → 直接返回兜底回复              │  │
│  │                                                             │  │
│  │  "抱歉，我现在有点忙，稍后再聊好吗？"                      │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  60秒后，试探 (HALF_OPEN):                                       │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  你: "在吗？"                                              │  │
│  │  → 试探性调用LLM                                           │  │
│  │  → 成功？ → 回到正常状态                                   │  │
│  │  → 失败？ → 继续熔断                                       │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  💡 好处: 不会一直调用挂掉的LLM，加重故障                        │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  第二层防护: 💾 响应缓存                                         │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  就像你的记事本: 问过的问题记下来，下次直接看答案                │
│                                                                  │
│  你第一次问: "今天几号？"                                        │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  → 缓存里没有 → 调用LLM → 返回 "今天是7月30日"            │  │
│  │  → 把答案存到缓存                                          │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  你又问: "今天几号？"                                            │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  → 缓存里有！→ 直接返回 "今天是7月30日" (不用调LLM)       │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  缓存规则:                                                       │
│  • 最多存100条                                                   │
│  • 1小时后过期                                                   │
│  • 超过100条，最久没用的被挤掉 (LRU)                            │
│                                                                  │
│  💡 好处: 相同问题秒回，省钱省时间                               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  第三层防护: 🆘 兜底回复                                         │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  如果LLM真的挂了，缓存也没有:                                    │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  你: "今天心情不错"                                        │  │
│  │  → LLM挂了                                                │  │
│  │  → 缓存也没有                                              │  │
│  │  → 返回兜底回复:                                           │  │
│  │                                                             │  │
│  │  "抱歉，我现在有点忙，稍后再聊好吗？"                      │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  💡 好处: 你永远不会看到"系统错误"                               │
│     小柏永远能回复，只是有时候回复没那么智能                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  三层防护的调用顺序:                                             │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你发消息                                                        │
│     │                                                            │
│     ▼                                                            │
│  ┌─────────────┐                                                │
│  │  检查熔断   │ ← 如果熔断了，直接跳到兜底                    │
│  └──────┬──────┘                                                │
│         │ 没熔断                                                 │
│         ▼                                                        │
│  ┌─────────────┐                                                │
│  │  检查缓存   │ ← 如果有缓存，直接返回                        │
│  └──────┬──────┘                                                │
│         │ 没缓存                                                 │
│         ▼                                                        │
│  ┌─────────────┐                                                │
│  │  调用LLM    │                                                │
│  └──────┬──────┘                                                │
│         │                                                        │
│     ┌───┴───┐                                                    │
│     │       │                                                    │
│   成功    失败                                                    │
│     │       │                                                    │
│     ▼       ▼                                                    │
│  存缓存   返回兜底                                               │
│  返回回复                                                         │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
