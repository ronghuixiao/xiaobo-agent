所有数据存在一个SQLite文件: memory.db

8张表:
┌──────────────────────────────────────────────────────────────────┐
│  conversations  对话记录 (每句话都存)                           │
│  facts          提取的事实 (8种类型)                            │
│  emotions       情绪记录 (8种情绪)                              │
│  associations   关联索引 (关键词→消息映射)                      │
│  tasks          任务管理 (用户任务+系统任务)                    │
│  summaries      对话摘要 (压缩旧对话)                           │
│  embeddings     向量缓存 (避免重复计算)                         │
│  learning_log   学习记录 (学习内容+理解程度)                    │
└──────────────────────────────────────────────────────────────────┘

14个索引 (加速查询):
  idx_conv_session    → 按会话查对话
  idx_conv_timestamp  → 按时间查对话
  idx_facts_type      → 按类型查事实
  idx_facts_subject   → 按主题查事实
  idx_assoc_keyword   → 按关键词查关联
  ... 等等

WAL模式:
  支持同时读写，不会锁表
  后台任务写数据时，API还能读

为什么用SQLite？
  • 单文件，不需要额外服务
  • 所有数据在一起，事务保证一致性
  • 个人助手数据量不大，够用
