问题: 如果你说了10次"我喜欢火锅"，小柏会记10遍吗？

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  ❌ 笨办法 (Insert): 每次都记新的                                │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你说: "我喜欢火锅"        → 记录1: 荣慧喜欢火锅                │
│  你说: "火锅真的好吃"      → 记录2: 荣慧喜欢火锅                │
│  你说: "今天又吃了火锅"    → 记录3: 荣慧喜欢火锅                │
│                                                                  │
│  事实本里:                                                       │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  荣慧喜欢火锅                                              │  │
│  │  荣慧喜欢火锅                                              │  │
│  │  荣慧喜欢火锅                                              │  │
│  │  ... (重复10遍)                                            │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  问题: 152条事实，70%是重复的，AI看的眼花                        │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  ✅ 聪明办法 (Upsert): 有就更新，没有才新建                      │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  判断依据: subject(谁) + fact_type(什么类型)                     │
│                                                                  │
│  你说: "我喜欢火锅"                                              │
│  → 查找: subject="荣慧" + type="preference" 有吗？没有           │
│  → 新建: 荣慧喜欢火锅                                            │
│                                                                  │
│  你说: "火锅真的好吃"                                            │
│  → 查找: subject="荣慧" + type="preference" 有吗？有了！         │
│  → 更新: 荣慧喜欢火锅 (更新时间戳)                               │
│                                                                  │
│  你说: "现在不太喜欢火锅了，更喜欢日料"                          │
│  → 查找: subject="荣慧" + type="preference" 有吗？有了！         │
│  → 更新: 荣慧喜欢日料 (内容也更新)                               │
│                                                                  │
│  事实本里:                                                       │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  荣慧喜欢日料 (最新)                                       │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  效果: 152条 → 30-40条，去重率70%+                               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

💡 生活中的比喻:
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  Upsert 就像你的通讯录:                                          │
│                                                                  │
│  张三换手机号了:                                                 │
│  • Insert: 再加一条"张三 138xxxx" → 通讯录里有两个张三          │
│  • Upsert: 找到张三，更新号码 → 通讯录里只有一个张三            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
