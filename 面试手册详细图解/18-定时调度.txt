┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  注册的定时任务:                                                 │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  📊 日报生成                                               │  │
│  │  频率: 每天22:00                                           │  │
│  │  做什么: 汇总今天的对话、情绪、任务完成情况，生成日报     │  │
│  │  发到: 微信                                                │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  ☀️ 早安签到                                               │  │
│  │  频率: 每天08:00                                           │  │
│  │  做什么: 发早安问候                                        │  │
│  │  发到: 微信                                                │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  💗 主动关怀检查                                           │  │
│  │  频率: 每4小时                                             │  │
│  │  做什么: 检查4条规则，看要不要主动关心                     │  │
│  │  发到: 微信 (如果触发)                                     │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  📋 任务提醒                                               │  │
│  │  频率: 每30分钟                                            │  │
│  │  做什么: 检查有没有到时间的待办任务，提醒你               │  │
│  │  发到: 微信 (如果触发)                                     │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  怎么实现的？ (60行代码)                                         │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  class CronScheduler:                                            │
│      # 两种调度模式:                                             │
│                                                                  │
│      # 1. 每日定时: schedule_daily("日报", 22, 0, generate)     │
│      #    每天22:00执行                                          │
│                                                                  │
│      # 2. 间隔执行: schedule_interval("主动关怀", 4h, check)    │
│      #    每4小时执行                                            │
│                                                                  │
│  主循环:                                                         │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  while True:                                               │  │
│  │      # 检查跨天                                             │  │
│  │      if 今天 != 上次记录的日期:                             │  │
│  │          触发跨天回调 (创建新一天的系统任务)               │  │
│  │                                                             │  │
│  │      # 检查每个定时任务                                     │  │
│  │      for task in tasks:                                     │  │
│  │          if 到时间了:                                       │  │
│  │              执行任务                                       │  │
│  │                                                             │  │
│  │      sleep(60)  # 每分钟检查一次                           │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  💡 为什么自己写60行，不用APScheduler？                          │
│  • APScheduler太重，需要额外安装                                 │
│  • 项目只需要两种调度模式，60行够了                              │
│  • 自己写更灵活，比如跨天检测                                    │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
