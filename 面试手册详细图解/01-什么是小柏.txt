║                    🤖 什么是小柏？                               ║
╚══════════════════════════════════════════════════════════════════╝

想象一下，你有一个朋友叫小柏。
你跟它聊天，它会记住你说过的所有事情。

┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   你: "我今天学了Python"                                     │
│                     ↓                                        │
│   小柏 (在小本本上记下来):                                   │
│   ┌────────────────────────────────────────────────────┐     │
│   │ 📝 荣慧在学Python                                  │     │
│   │ 😊 她看起来挺开心的                                │     │
│   │ 🏷️ 标签: 编程, 学习                                │     │
│   └────────────────────────────────────────────────────┘     │
│                     ↓                                        │
│   小柏: "不错啊，学到哪了？"                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘

过了一周，你又说:
┌──────────────────────────────────────────────────────────────┐
│   你: "Python学到什么程度了？"                                │
│                     ↓                                        │
│   小柏 (翻小本本):                                           │
│   ┌────────────────────────────────────────────────────┐     │
│   │ 📝 上次荣慧说在学Python，那是7天前                 │     │
│   └────────────────────────────────────────────────────┘     │
│                     ↓                                        │
│   小柏: "你上周开始学的，现在进展怎么样？"                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘

💡 小柏就像一个记忆力超好的朋友:
   - 你说什么它都记得
   - 它会主动关心你
   - 聊天很自然，不像机器人
