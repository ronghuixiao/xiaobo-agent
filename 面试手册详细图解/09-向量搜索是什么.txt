问题: 你说"之前学的那个传播算法"，小柏怎么找到"反向传播"的对话？

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  ❌ 关键词搜索: 找不到！                                         │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你搜: "传播算法"                                                │
│  数据库里: "反向传播"                                            │
│                                                                  │
│  关键词匹配: "传播算法" ≠ "反向传播" → 找不到！                  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  ✅ 向量搜索: 用"意思"来找                                       │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  第一步: 把文字变成数字 (叫"embedding")                          │
│                                                                  │
│  "传播算法" → [0.12, 0.85, -0.34, 0.67, ...]  (768个数字)       │
│  "反向传播" → [0.15, 0.82, -0.31, 0.70, ...]  (768个数字)       │
│  "今天天气" → [-0.45, 0.12, 0.78, -0.23, ...] (768个数字)       │
│                                                                  │
│  第二步: 比较数字的"距离"                                        │
│                                                                  │
│  "传播算法" 和 "反向传播":                                       │
│  [0.12, 0.85, -0.34] vs [0.15, 0.82, -0.31]                     │
│  数字很接近！→ 相似度 0.92 (很高)                                │
│                                                                  │
│  "传播算法" 和 "今天天气":                                       │
│  [0.12, 0.85, -0.34] vs [-0.45, 0.12, 0.78]                     │
│  数字差很远！→ 相似度 0.15 (很低)                                │
│                                                                  │
│  第三步: 找最相似的                                              │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  查询: "传播算法"                                          │  │
│  │                                                             │  │
│  │  结果1: "反向传播" 相似度 0.92 ✓ 最相关                    │  │
│  │  结果2: "梯度下降" 相似度 0.78 ✓ 相关                      │  │
│  │  结果3: "今天天气" 相似度 0.15 ✗ 不相关                    │  │
│  │                                                             │  │
│  │  取相似度 >= 0.3 的，最多取5条                             │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

💡 生活中的比喻:
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  向量搜索就像找"意思相近"的朋友:                                 │
│                                                                  │
│  你说: "我想找那个喜欢编程的朋友"                                │
│                                                                  │
│  关键词搜索: 只找名字叫"编程"的人 → 找不到                      │
│  向量搜索: 找"喜欢写代码"、"搞技术"的人 → 找到了！              │
│                                                                  │
│  因为"编程"和"写代码"在数字空间里很接近                         │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  技术细节:                                                       │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  1. Embedding模型: Ollama的nomic-embed-text                      │
│     把文字变成768维的数字向量                                    │
│                                                                  │
│  2. 存储: SQLite的BLOB字段                                       │
│     用struct.pack把float数组打包成bytes存进去                   │
│     好处: 不用额外装向量数据库                                   │
│                                                                  │
│  3. 相似度计算: 手写余弦相似度                                   │
│     cosine = (A·B) / (|A| × |B|)                                │
│     不依赖numpy，纯Python实现                                    │
│                                                                  │
│  4. 缓存: 计算过的embedding存起来                                │
│     下次查同一个东西不用重新算                                   │
│                                                                  │
│  5. 阈值: 0.3 (比较宽松)                                        │
│     宁可多找一些，不要漏掉                                       │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
