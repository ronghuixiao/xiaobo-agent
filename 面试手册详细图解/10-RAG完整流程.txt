RAG = Retrieval Augmented Generation = 检索增强生成

翻译成人话: 先翻小本本找相关记忆，再让AI根据记忆回答

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  你问: "我之前学的那个传播算法怎么样了？"                        │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  Step 1: 把你的问题变成数字                                │  │
│  │  ────────────────────────────────────────────────────────  │  │
│  │                                                             │  │
│  │  "我之前学的那个传播算法怎么样了？"                        │  │
│  │                         ↓                                   │  │
│  │  Embedding模型 (nomic-embed-text)                          │  │
│  │                         ↓                                   │  │
│  │  [0.12, 0.85, -0.34, 0.67, ...]  (768个数字)              │  │
│  │                                                             │  │
│  │  💡 有缓存就用缓存，没有才计算                             │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  Step 2: 拿着数字去记忆里搜                                │  │
│  │  ────────────────────────────────────────────────────────  │  │
│  │                                                             │  │
│  │  数据库里存着所有对话的embedding:                          │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │ 7月20日 "学了反向传播" → [0.15, 0.82, -0.31, ...]    │  │  │
│  │  │ 7月21日 "今天吃了火锅" → [-0.45, 0.12, 0.78, ...]    │  │  │
│  │  │ 7月22日 "链式法则搞懂了" → [0.14, 0.80, -0.29, ...]  │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  │                                                             │  │
│  │  计算相似度:                                                │  │
│  │  问题 vs "学了反向传播" = 0.92 ✓                           │  │
│  │  问题 vs "今天吃了火锅" = 0.15 ✗                           │  │
│  │  问题 vs "链式法则搞懂了" = 0.88 ✓                         │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  Step 3: 过滤 + 排序，取最好的5条                          │  │
│  │  ────────────────────────────────────────────────────────  │  │
│  │                                                             │  │
│  │  条件:                                                      │  │
│  │  • 相似度 >= 0.3 (太低的不相关)                            │  │
│  │  • 只要用户说的话 (不要AI的回复，避免重复)                 │  │
│  │  • 最多取5条                                               │  │
│  │                                                             │  │
│  │  结果:                                                      │  │
│  │  1. [7月20日] "学了反向传播" (相似度0.92)                  │  │
│  │  2. [7月22日] "链式法则搞懂了" (相似度0.88)                │  │
│  │  3. [7月18日] "前向传播理解了" (相似度0.75)                │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  Step 4: 把找到的记忆写进"提示卡"                          │  │
│  │  ────────────────────────────────────────────────────────  │  │
│  │                                                             │  │
│  │  系统提示里加一段:                                          │  │
│  │  ## 相关历史记忆（语义检索）                                │  │
│  │  [7月20日] 荣慧: 学了反向传播                               │  │
│  │  [7月22日] 荣慧: 链式法则搞懂了                             │  │
│  │  [7月18日] 荣慧: 前向传播理解了                             │  │
│  │                                                             │  │
│  │  → AI看到这些记忆后，就能准确回答                          │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  Step 5: AI根据记忆回答                                    │  │
│  │  ────────────────────────────────────────────────────────  │  │
│  │                                                             │  │
│  │  AI看到:                                                    │  │
│  │  • 7月20日学了反向传播                                      │  │
│  │  • 7月22日链式法则搞懂了                                    │  │
│  │  • 今天是7月30日                                            │  │
│  │                                                             │  │
│  │  AI回答: "你上周学的反向传播，链式法则已经搞懂了，          │  │
│  │          现在是不是该试试实际应用了？"                      │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

💡 为什么需要RAG？
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  没有RAG:                                                        │
│  你: "我之前学的那个传播算法怎么样了？"                          │
│  AI: "抱歉，我不记得你之前学过什么"                              │
│      (AI没有记忆，每次对话都是从零开始)                          │
│                                                                  │
│  有RAG:                                                          │
│  你: "我之前学的那个传播算法怎么样了？"                          │
│  AI: "你上周学的反向传播，链式法则搞懂了"                        │
│      (先翻记忆，再回答，像真正的朋友)                            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
