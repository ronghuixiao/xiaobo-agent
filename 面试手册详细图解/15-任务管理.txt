
╔══════════════════════════════════════════════════════════════════╗
║            📋 任务管理                                            ║
║         小柏怎么帮你管任务？                                      ║
╚══════════════════════════════════════════════════════════════════╝

小柏能帮你管理待办任务，有3种来源:

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  来源1: 你说的任务 (用户任务)                                    │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你: "今日任务：背单词；刷题；看论文"                            │
│                                                                  │
│  小柏识别:                                                       │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  正则匹配: "今日任务：(.*)"                                │  │
│  │  分割: ["背单词", "刷题", "看论文"]                        │  │
│  │  保存: tasks表，user-前缀                                  │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  小柏: "好的，3个任务已记录"                                     │
│                                                                  │
│  💡 用正则匹配，不用LLM，100%准确，0延迟                         │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  来源2: 系统自动创建 (系统任务)                                  │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  每天自动创建的任务:                                             │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  ⬜ 早间签到 (8:00触发)                                    │  │
│  │  ⬜ 生成日报 (22:00触发)                                   │  │
│  │  ⬜ 主动关怀 (每4小时检查)                                 │  │
│  │  ⬜ 任务提醒 (每30分钟检查)                                │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  跨天时自动创建新一天的系统任务                                  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  任务完成检测: AI来判断                                          │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你: "背完了"                                                    │
│                                                                  │
│  小柏把任务列表和你说的话一起发给AI:                             │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  提示: "今天的待办任务:                                    │  │
│  │         - 背单词                                            │  │
│  │         - 刷题                                              │  │
│  │         - 看论文                                            │  │
│  │                                                             │  │
│  │         用户说: 背完了                                    │  │
│  │         哪些任务完成了？返回JSON"                           │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  AI返回: [{"task_id": "xxx", "completed": true}]                │
│                                                                  │
│  小柏: ✅ 背单词 → 已完成                                        │
│                                                                  │
│  💡 为什么用AI不用正则？                                         │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  "完成了" "做完了" "搞定了" → 正则能匹配                   │  │
│  │  "过了" "交了" "OK了" "done" → 正则要写很多规则            │  │
│  │  "那个单词终于背下来了" → 正则根本匹配不到                 │  │
│  │                                                             │  │
│  │  AI能理解各种表达方式，比正则灵活得多                       │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  任务移动: 正则检测                                              │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  你: "剩下的挪到明天"                                            │
│                                                                  │
│  小柏识别:                                                       │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  正则: "挪到明天" "移到明天" "推到明天"                    │  │
│  │  动作: 把未完成的任务due_date改成明天                       │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  小柏: ✅ 已移到明天                                             │
│                                                                  │
│  💡 在LLM回复前就执行，不需要等AI判断                            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  两种检测方式的对比:                                             │
│  ────────────────────────────────────────────────────────────    │
│                                                                  │
│  ┌─────────────┬──────────────────┬──────────────────────────┐  │
│  │    功能     │      方式        │        为什么            │  │
│  ├─────────────┼──────────────────┼──────────────────────────┤  │
│  │ 列表检测    │ 正则匹配         │ 格式固定，100%准确       │  │
│  │ 完成检测    │ LLM判断          │ 需要理解语义             │  │
│  │ 移动检测    │ 正则匹配         │ 格式固定，快速执行       │  │
│  └─────────────┴──────────────────┴──────────────────────────┘  │
│                                                                  │
│  💡 混合方案: 能用正则就用正则，需要理解语义才用LLM              │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
