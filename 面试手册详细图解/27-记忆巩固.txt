║            🔄 记忆巩固
║         数据库会越来越大，怎么清理？
╚══════════════════════════════════════════════════════════════════╝

问题: 3个月后，数据库可能有几万条记录，查询变慢

解决方案: 每天凌晨3点自动执行记忆巩固

┌──────────────────────────────────────────────────────────────────┐
│  1. Summarizer (摘要器)                                          │
│  ────────────────────────────────────────────────────────────    │
│  把7天前的旧对话压缩成1-2句摘要                                  │
│                                                                  │
│  原始: 20条对话记录                                              │
│  压缩: "7月15日聊了Python学习和火锅"                            │
│                                                                  │
│  好处: 占用空间小，但保留了关键信息                              │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│  2. Forgetter (遗忘器)                                           │
│  ────────────────────────────────────────────────────────────    │
│  三种清理策略:                                                   │
│                                                                  │
│  策略1: 过期遗忘                                                 │
│  • 30天前的临时事件 → 删除                                      │
│  • "7月1日吃了火锅" 一个月后就不重要了                          │
│                                                                  │
│  策略2: 重复合并                                                 │
│  • 同subject的重复事实 → 只留最新一条                           │
│  • "喜欢火锅"出现10次 → 合并成1次                               │
│                                                                  │
│  策略3: 低置信度清理                                             │
│  • confidence < 0.3 的事实 → 删除                               │
│  • AI不太确定的事实，宁可删掉                                    │
└──────────────────────────────────────────────────────────────────┘

💡 就像人的记忆:
  • 短期记忆会遗忘 (过期遗忘)
  • 重复的事情记得更牢 (重复合并)
  • 不确定的事情容易忘 (低置信度清理)
